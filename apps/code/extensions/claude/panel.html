Claude

Claude reads the code you are working on and helps you write it, fix build errors and port programs to Banana OS.

It talks to the Anthropic API with your own API key (from console.anthropic.com, Settings > API Keys). The key is kept only on this computer, in ~/.bcode/state/claude, and sent only to api.anthropic.com.

Model:

Code blocks in answers have buttons to put them into the editor.
