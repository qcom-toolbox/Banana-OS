# Banana OS 0.4

## Highlights

- **Real bootable disk install.** `install` no longer just copies files to a persistent partition — it raw-copies the already-bootable GRUB hybrid ISO onto the target disk via a small ATAPI driver, then writes the filesystem right after it. Once installed, the disk boots Banana OS on its own; no `-cdrom` needed.
- **Persistent disk storage** via new `install`/`sync` shell commands, backing the filesystem with real disk I/O instead of RAM-only state.
- **Bash-compatible shell persona** alongside the stock `sh`, selectable at the prompt.
- A more Unix-like shell and filesystem overall (paths, commands, and behavior brought closer to POSIX conventions).

## Features

- Multi-terminal GUI: each terminal window now runs its own independent shell task instead of sharing one.
- GUI terminal windows scroll instead of cutting off output.
- Ctrl+Alt+Delete now closes the GUI.
- Real Synaptics PS/2 touchpad support (absolute mode + tap-to-click).
- Real wallpaper rendering (replacing the old procedural placeholder pattern), plus bilinear upscaling.
- Two new wallpapers: Azure Flow (now the default, with cached rendering) and Plain Black (10th wallpaper).

## Fixes

- Fixed massive lag after quitting the GUI.
- Fixed `task_yield()` self-switch corrupting the stack pointer.
- Fixed i386 SysV stack-alignment bug that crashed full-screen apps.
- Disabled SSE/MMX codegen — root cause of the full-screen-app crashes.
- Stopped guessing GDT selector values in the IDT/ISR code.
- Added IDT-based exception handling with a panic screen instead of silent triple-faults; fixed a font-table out-of-bounds read.
- Fixed boot hang on malformed/zero-size Multiboot2 tags.

## Other

- Version bumped to 0.4 across the boot menu, MOTD, `uname`/`hostname`, shell prompt, `htop`, `help`, and the GUI About dialog.
- Removed the `LICENSE:` line from `neofetch` output.
- README updated to document recent features, with a new GUI desktop screenshot.
